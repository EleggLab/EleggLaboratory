## 실제 남은 문제

### 1. 호랑이 자산이 아직 잘못 보인다
가장 분명한 문제다.

- 사용자 제공 원본 호랑이 아이콘은 [tiger-icon.png](C:/Users/rndhr/Documents/GitHub/EleggLaboratory/game_DEV/mobile-saju-fortune-toss/apps/toss-clean/assets/user-provided/today/tiger-icon.png) 이다.
- 그런데 실제 배포 화면의 `호랑이띠` 목록 타일은 이 원본이 아니라 다른 기존 일러스트를 보여준다.
- 상세 진입 후 상단 hero도 마찬가지로 사용자 원본이 아니라 다른 세로형/인물형 일러스트가 메인처럼 나온다.

즉 이번 빌드 기준으로는:
- 목록 타일도 잘못됨
- 상세 hero도 잘못됨

이건 단순 스타일 문제가 아니라 자산 경로 잠금 실패다.

### 2. 타로 허브는 동작은 되지만 시각 밀도가 아직 부족하다
- 현재 허브는 예전보다 좋아졌지만, 원본 모바일 앱과 비교하면 상단 hero와 2x2 모드 카드가 여전히 조금 비어 보인다.
- 구조는 맞고 깨지진 않지만, 출시 직전 완성도로는 한 번 더 압축이 필요하다.
- 특히 상단 hero는 아트 영역은 살아 있지만, 텍스트와 아트가 더 강하게 한 카드 안에서 묶여 보일 필요가 있다.

### 3. 홈 스크림은 개선됐지만 아직 완전히 자연스럽진 않다
- 홈은 전체적으로 훨씬 좋아졌다.
- 다만 상단/하단 어둡게 깔리는 영역이 아직 완전히 한 장의 연속 페이드처럼 보이진 않는다.
- 사용자가 지적한 “딱 잘린 검은 막” 단계는 벗어났지만, 최종 마감 단계에서는 더 부드럽게 갈 수 있다.

### 4. 하단바는 usable 하지만 최종 시안급은 아니다
- 현재 하단바는 기능적으로는 괜찮다.
- 다만 원본 모바일 앱의 `간결한 아이콘형` 감성과 비교하면 아직 더 단순하고 읽기 쉬운 선형 시안으로 정리할 여지가 있다.
- 특히 `홈`만 강조되고 나머지는 깔끔하게 받쳐주는 구조를 더 또렷하게 만들 수 있다.

### 5. 사주 결과/Q&A는 이번 빌드에서 다시 명확히 잠가야 한다
- 이번 순회에서는 `사주 입력 -> 결과 -> 분야별 Q&A`를 같은 흐름으로 다시 깔끔하게 잠그지 못했다.
- 입력 상태와 키보드, 달력 선택 상태가 캡처 자동화와 겹치면서 결과 화면 확인이 흐려졌다.
- 이전 빌드들에서 Q&A가 실제로 뜬 적은 있으므로, 현재 빌드에서 완전히 죽었다고 단정할 단계는 아니다.
- 하지만 출시 전 마지막 잠금 관점에서는 이건 `반드시 다시 확인할 기능`이다.
