# Merge Tactics v2.0

Flutter-based Android portrait project.

## Included
- Lobby scene with mapped UI assets and currency HUD
- In-game core loop: summon, drag-merge, wave combat, synergies, skills
- Unit codex with locked silhouette + lock icon state
- Gacha flow with 100-gem cost and 70/25/5 tier probabilities
- Battle pass with free/premium tracks and reward claim animation
- Account EXP/level rewards and PvP unlock state
