# App Store 메타 초안

## 출시 방향

- 형태: 무료 앱
- 광고: 없음
- 인앱결제: 없음
- 핵심 가치: 사주, 타로, 주역, 오늘 운세를 한 앱에서 간단하게 확인

## 앱 이름 후보

- 종합 운세
- 사주 Companion
- 오늘의 운세

## 부제 후보

- 사주, 타로, 주역을 한 번에
- 광고 없이 보는 오늘의 운세
- 사주와 타로를 한 앱에서

## 설명 초안

사주, 타로, 주역, 오늘 운세를 한 앱에서 간편하게 확인할 수 있는 무료 운세 앱입니다.

- 사주 풀이와 연운 / 월운 확인
- 타로 카드 선택과 결과 보기
- 주역 흐름 보기
- 오늘 운세 간단 확인

복잡한 회원가입이나 결제 없이 바로 사용할 수 있도록 구성했습니다.
광고나 인앱결제 없이 핵심 기능에 집중했습니다.
