# Workflow Templates (Script Design Reference)

## 1) Minimal Agent Loop
1. Plan (scope/done)
2. Act (small diff)
3. Verify (tests/checks)
4. Report (changed files + evidence)

## 2) Research Refresh Loop
1. Collect
2. Deep collect
3. Triage
4. Backlog update
5. Report

## 3) Release Loop
1. Verify
2. Security checks
3. Tag + changelog
4. Rollback note update
