## 공통 UX 패턴 (심플함의 핵심)
1. **첫 화면 3초 규칙**: 제목 + 메인 CTA 1개 + 서브버튼 1~2개
2. **원탭 루프**: 이동/액션은 자동 또는 단순 터치, 복잡한 튜토리얼 제거
3. **재화 최소화**: 코인(기본) + 보조재화(선택) 2종 이내
4. **정보 밀도 낮춤**: HUD 핵심 3개(점수/재화/진행도)
5. **큰 버튼 + 큰 카드**: 텍스트보다 시각적 블록 우선
6. **한 화면 한 목적**: 로비/플레이/결과 분리, 멀티패널 최소화
7. **짧은 세션**: 2~3분 플레이 → 즉시 보상 → 재도전
8. **강한 피드백**: 성공 연출(색/사운드/진동), 실패도 빠른 재시작

## 현재 3개 프로젝트 적용 방향

### 1) toss-breaking-block-v2-webapp
- 로비 CTA를 `플레이` 단일 우선
- 클래스/모드 선택은 3개 카드만 노출
- 전투 HUD: 생명/점수/웨이브만 유지
- 결과: `다시하기` + `로비`만

### 2) merge-tactics-ux-overhaul
- 로비: 설명 텍스트 축소, 튜토리얼 4줄 고정
- 전투 전 `머지`와 `전투 시작` 2버튼만 메인
- 카드/상점은 탭 분리 유지하되 정보량 절반 축소
- 용어 단순화: 트로피/골드/젬 중심

### 3) toss-allages-ai-game-webapp
- 전체이용가 톤 유지(공격적 용어 제거)
- 캐릭터/장애물 명칭을 친근하게 통일
- AI 배경 적용 시 UI safe area 확보(상단15%/하단20%)
