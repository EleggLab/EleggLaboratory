# StackCraft 기반 성인 판타지 종족-계보 게임 기획 초안 v0.1
## 범위: 건물 제외 / 종족 변이 / 호감도 / 자동 생태 / 교배 / 가계도 집중

---

## 0. 이 문서의 목적

이 문서는 StackCraft 에셋 위에 얹을 **1차 핵심 시스템 기획서**다.  
이번 단계의 목표는 다음 6가지를 고정하는 것이다.

1. 플레이어 주인공 구조  
2. 장소 기반 종족 변이 구조  
3. 비주인공 생물 자동 행동 구조  
4. 선물-호감도-교배 해금 구조  
5. 적색(마족/적대) 카드의 전투-정화-동료화 구조  
6. 이름/종족/혈통/가계도 데이터 구조

이번 버전에서는 **건물, 상점, 집창촌, 생산시설, 경제 메타**를 의도적으로 보류한다.  
그 이유는 현재 게임의 정체성이 "카드 건설 시뮬"보다 "카드 기반 종족 생태 + 관계/번식 + 계보 관리"에 더 가깝기 때문이다.

---

## 1. 리서치 기반 결론 요약

### 1-1. 원작 Stacklands에서 반드시 계승할 것
- 카드끼리 겹치면 상호작용하는 구조
- 짧은 주기 루프(문/데이 사이클)
- 카드의 역할이 시각적으로 바로 읽히는 색/분류 체계
- 자동 전투, 간단한 수치, 짧은 작업 시간, 반복 가능한 탐험/장소 카드
- 아이디어/발견 기반 해금 감각

### 1-2. 이번 게임에서 과감히 바꿀 것
- 부스터 팩 중심 확장 -> **상단 고정 장소 카드 중심 확장**
- 마을/건물 중심 성장 -> **개체/관계/번식/혈통 중심 성장**
- 대규모 카드 수집 -> **소규모 종족/개체를 깊게 관리**
- 플레이어의 모든 행동이 직접 조작 -> **비주인공 생물의 자율 행동 강화**
- 전투는 단순 위험 요소 -> **적색 카드의 포획/정화/동료화 경로 추가**

### 1-3. 에셋 적합성 판단
StackCraft의 공개 설명상 이 에셋은 다음을 이미 제공한다.
- 스태킹 규칙 매트릭스
- Day Cycle(Feeding / Selling / Encounters / New Day)
- 시간 기반 레시피/제작
- RPS 기반 전투
- 퀘스트
- Day 기반 동적 인카운터
- ScriptableObject 중심 데이터 확장
- 저장 시스템

즉, **카드 상호작용, 날짜 루프, 전투, 인카운터, 데이터 드리븐 콘텐츠 추가**까지는 에셋 강점 안에 있다.  
반대로 이번 게임의 차별점인 아래 요소는 커스텀 구현 비중이 높다.
- 카드가 스스로 움직이는 자율 행동 AI
- 호감도/성향/선물 선호도
- 교배 잠금 상태와 임신/출산
- 개체 단위 이름/가계도/부모-자식 링크
- 한 캐릭터의 "인간 기원 유지 + 현재 종족 변이" 이력

즉 **StackCraft는 기반 엔진으로는 적합하지만, 이번 게임의 핵심 가치인 생태/관계/혈통 계층은 별도 시스템으로 덧씌워야 한다.**

## 2. 코어 판타지

플레이어는 인간 남성 1장, 인간 여성 1장의 **주인공 카드 2장**을 가진다.  
이 두 카드는 단순한 소모성 주민이 아니라 게임의 기준점이다.

- 두 카드는 고유 ID를 가진다.
- 두 카드는 이름이 있다.
- 두 카드는 혈통의 시조다.
- 두 카드는 장소를 통해 다양한 종족 형태로 변이할 수 있다.
- 두 카드는 다른 종족과 관계를 만들고 후손을 남긴다.
- 후손과 주변 개체는 전부 이름과 부모 정보를 가진다.

플레이어가 관리하는 것은 건물이 아니라 **혈통 네트워크**다.  
게임의 메타 질문은 다음으로 바뀐다.

- 누구를 어떤 장소에 보내 어떤 형태로 만들 것인가?
- 누구에게 어떤 선물을 줘야 관계가 열린는가?
- 어떤 적대 종족을 전투로 정화해서 교배 가능 대상으로 만들 것인가?
- 같은 종족 개체를 방치해 자연 번식을 유도할 것인가?
- 어떤 혈통이 어떤 종족 조합으로 진화했는가?

## 3. 핵심 플레이 루프

## 3-1. 메인 루프

1. 인간 주인공 또는 동료를 장소 카드에 보낸다.  
2. 장소 결과로 종족 변이 또는 선물 자원이 나온다.  
3. 선물 자원을 사용해 특정 종족의 호감도를 올린다.  
4. 호감도가 기준 이상이 되면 교배 가능 상태가 열린다.  
5. 교배 진행 중 카드는 잠금 상태가 된다.  
6. 시간이 흐르면 임신/출산/신규 개체 생성이 발생한다.  
7. 신규 개체는 이름, 성별, 종족, 부모 정보, 세대 번호를 가진다.  
8. 비주인공 생물은 같은 종-이성 조합일 때 자율적으로 교배를 시도한다.  
9. 적색 적대 개체는 일정 단계/일차에 맞춰 출현한다.  
10. 전투로 승리하면 일부 적색 개체를 정화해서 일반 카드색 개체로 바꾼다.  
11. 이 정화 개체는 이후 선물/호감도/교배 시스템에 편입된다.  
12. 가계도와 카드 상세 화면을 통해 혈통을 확인하고 다음 조합을 설계한다.

## 3-2. 감정 곡선
- 초반: 인간 2장과 소수 장소로 첫 변이 경험
- 중반: 호감도 선물 루프가 열리며 자율 생태가 형성됨
- 중후반: 적색 마족을 정화해 희귀 혈통이 늘어남
- 후반: 혈통 관리, 교배 조합, 세대 누적, 희귀 종족 도감화

## 4. 플레이어가 조작하는 주인공 구조

## 4-1. 주인공 고정 규칙
초기 카드:
- Protagonist_Male_Human
- Protagonist_Female_Human

필수 규칙:
- GameStart 시 반드시 존재
- 일반 소모 카드처럼 완전히 삭제되지 않음
- 현재 종족이 바뀌어도 `Origin = Human` 이력은 유지
- 현재 종족이 변해도 `CharacterID`는 유지
- 가계도 루트 노드로 항상 추적 가능

## 4-2. 주인공의 변이 개념
"인간을 장소에 보낸다"는 것은 주인공 정체성 삭제가 아니라  
**인간 기원의 주인공이 특정 종족 형태로 재구성되는 것**으로 정의한다.

예:
- 에단(남/인간) -> 숲 탐험 후 `에단 / 엘프형`
- 리아(여/인간) -> 바다 탐험 후 `리아 / 인어형`

이 방식의 장점:
- 플레이어가 주인공을 잃었다는 감각이 적음
- 이름/혈통/서사가 유지됨
- 한 인물이 여러 종족 형태를 거친 기록을 남길 수 있음
- 상세 보기와 가계도에 "형태 변화 이력"을 적재 가능

## 5. 카드 분류 체계

## 5-1. 카드 대분류
1. 주인공 카드
2. 일반 생물 카드
3. 적색 적대 생물 카드
4. 장소 카드
5. 선물/자원 카드
6. 출산/후손 카드
7. 상태 카드(임신, 교배중, 정화완료 등)
8. 시스템 카드(알림, 퀘스트, 혈통 마일스톤)

## 5-2. 시각 색상 원칙
- 인간/기본 동료: 아이보리-베이지
- 자연계 종족(엘프, 드워프, 인어 등): 종족별 파생색
- 적색 마족/적대 개체: 붉은색 카드
- 장소 카드: 상단 고정 보라/청록 계열
- 선물/자원 카드: 원작 Stacklands 계열의 식별색 유지
- 임신/교배 잠금 상태: 카드 상단 오버레이 배지 표시

## 5-3. 카드 헤더 정보
모든 생물 카드 헤더 필수 항목:
- 이름
- 성별
- 현재 종족
- 성향 아이콘(온순/공격적/수줍음/탐식 등)
- 호감도 등급
- 상태(Idle / 탐험중 / 전투중 / 교배중 / 임신중 / 휴식중)

## 6. 종족 구성: 소규모 집중형

## 6-1. 초기 운영 종족(1차 범위)
1. Human
2. Elf
3. Dwarf
4. Lizardfolk
5. Merfolk
6. Orc
7. Ogre
8. Centaur

총 8종으로 제한한다.  
이 수는 "작지만 조합과 혈통은 깊게"라는 방향에 맞다.

## 6-2. 종족 역할 구도

### Human
- 기준 종족
- 주인공의 원형
- 평균 선호, 평균 능력
- 대부분의 장소와 상호작용 가능

### Elf
- 숲 계열
- 꽃/열매/정성 선물 선호
- 호감도 상승이 쉬우나 공격성 낮음
- 교배 해금 시 후손에 "친화적 성향" 부여 확률 높음

### Dwarf
- 산 계열
- 광물/반짝이는 물건/뿌리채소 선호
- 작업 시간이 안정적
- 후손에게 "강건" 계열 특성 부여 가능

### Lizardfolk
- 늪 계열
- 생고기/버섯/습지 자원 선호
- 초기 호감도 난이도 중간
- 후손에게 "습지 적응" 태그 부여 가능

### Merfolk
- 바다 계열
- 물고기/조개/해초류 선호
- 수변 장소 상호작용 우수
- 후손에게 "수중 친화" 태그 부여 가능

### Orc (적색 -> 정화 가능)
- 적대적 등장
- 전투 승리 전에는 호감도 상승 불가
- 정화 후 고기 선호, 직접적 선물 반응 큼
- 후손은 힘/공격성 계열 확률이 높음

### Ogre (적색 -> 정화 가능)
- 적대적 등장
- 정화 난이도 높음
- 육류/거대한 식량 선호
- 후손 수 적지만 체력 계열 강함

### Centaur (적색 -> 정화 가능)
- 적대적 등장
- 정화 후 채소/과실/자연물 선호
- 이동/탐험 계열 특성 우수
- 후손에게 빠른 작업/탐험 보너스 부여 가능

## 7. 장소 카드 시스템

## 7-1. 장소 카드 기본 원리
상단 UI 영역에 **항상 노출되는 고정 장소 카드**를 둔다.

초기 4장:
- 숲
- 바위산
- 늪
- 바다

이 장소들은 기존 Stacklands의 팩 구매 기능을 대체하는 **세계 확장 슬롯**이다.

## 7-2. 장소 카드 상호작용 규칙
- 인간 기원 캐릭터를 장소 카드에 올리면 탐험/변이 타이머 시작
- 타이머 종료 시 해당 캐릭터는 같은 ID를 유지한 채 현재 종족이 장소 풀 중 하나로 변경
- 동시에 장소 전용 선물 자원 1~2개 생성 가능
- 비인간 캐릭터를 장소에 넣으면 기본적으로 변이가 아니라 채집/탐색만 수행
- 적색 적대 카드는 플레이어가 자유롭게 장소에 넣지 못함

## 7-3. 장소별 결과 풀

### 숲
변이 우선 풀:
- Elf

부가 산출:
- Flower
- Berry
- Herb
- Vine

### 바위산
변이 우선 풀:
- Dwarf

부가 산출:
- Stone
- Shiny Stone
- Root Carrot
- Ore Fragment

### 늪
변이 우선 풀:
- Lizardfolk

부가 산출:
- Mud
- Mushroom
- Soil
- Raw Meat(저확률)

### 바다
변이 우선 풀:
- Merfolk

부가 산출:
- Fish
- Shell
- Seaweed
- Pearl Shard(희귀)

## 7-4. 장소 시간 규칙
권장 기본값:
- 인간 변이 탐험: 45초
- 비인간 채집 탐험: 35초
- 주인공 특수 연출 포함 시: 50~60초

이 수치는 원작의 위치 탐험 감각을 유지하되, 본작이 종족 변이 자체를 핵심 보상으로 가지므로 약간 더 짧게 잡는다.

## 8. 적색 카드(마족/적대 개체) 설계

## 8-1. 적색 카드의 의미
적색 카드는 단순 색변화가 아니다.  
이 색은 아래 의미를 동시에 가진다.

- 플레이어 소유 불가 상태
- 호감도 상승 불가 상태
- 자율 공격 상태
- 교배 불가 상태
- 정화 전용 대상 상태

## 8-2. 적색 등장 종족
1. Orc
2. Ogre
3. Centaur

## 8-3. 등장 규칙
- Day / Stage에 따라 인카운터로 등장
- 상단 Encounters 단계에서 보드에 투입
- 초기에는 단독 개체, 중반 이후 동일 종 2~3체 묶음 등장
- 일부는 남/여 성별을 가진 적색 상태로 등장

## 8-4. 정화 규칙
전투 승리 시 결과 중 하나:
- 처치
- 도주
- 정화 전환

이번 게임에서는 핵심 콘텐츠 확보를 위해  
**첫 조우 개체는 정화 전환 확률을 높게**, 이후는 일반 확률로 둔다.

권장 수치:
- 최초 종족 조우 승리 시 정화 전환 100%
- 이후 동일 종족 승리 시 35%
- 보스 개체는 별도 100% 또는 퀘스트 보상형

정화 완료 시:
- 카드 색이 기본 종족색으로 전환
- `Hostility = Neutralized`
- 호감도 시스템 활성화
- 선물 수령 가능
- 교배 가능 후보 편입

## 9. 호감도 시스템

## 9-1. 핵심 원칙
- 호감도는 **인간 측이 관계를 열기 위해 투자하는 자원**이다.
- 적색 상태에서는 호감도 상승 불가
- 교배는 호감도 해금 전까지 불가
- 남남 / 여여 교배 불가
- 같은 종족의 비주인공 남녀는 조건이 맞으면 자동 교배 가능

## 9-2. 호감도 단계
- 0~19 : 무관심
- 20~39 : 경계 해제
- 40~59 : 친밀
- 60~79 : 우호
- 80~99 : 교배 가능
- 100 : 각인/헌신 (추가 보너스)

## 9-3. 호감도 상승 경로
1. 선물 주기
2. 같은 장소 탐험 동행
3. 전투 구출
4. 특정 종족 선호 이벤트
5. 혈통 관련 퀘스트 완료

이번 단계에서는 **선물**을 핵심 경로로 둔다.

## 9-4. 선물 규칙
- 선물은 플레이어가 상대 카드 위에 올려 사용
- 1회 사용 시 카드가 소비됨
- 사용 즉시 호감도 수치 증감
- 선호 아이템일 경우 표정/하트/상태문구 출력
- 혐오 아이템일 경우 붉은 하트 깨짐/감점

## 11. 자동 생태 시스템

## 11-1. 비주인공 자동 행동 정의
주인공 이외의 생물 카드는 상태 머신 기반으로 자율 행동한다.

우선순위:
1. 교배중이면 교배 유지
2. 임신중이면 안전 행동
3. 허기 상태면 먹이 탐색
4. 같은 종-이성-성인-우호 대상이 근처에 있으면 교배 시도
5. 적색 카드면 인간/중립 종 공격 또는 위협 행동
6. 할 일이 없으면 배회/휴식

## 11-2. 자동 교배 조건
비주인공 남녀 개체가 자동 교배를 시작하려면:
- 둘 다 Adult
- 둘 다 같은 종족
- 성별이 다름
- 적대 상태 아님
- 현재 상태가 Idle 또는 FriendlyNear
- 호감도(내부 친밀도) >= 65
- 최근 교배 쿨다운 없음
- 굶주림/위험 패널티가 임계치 이하

## 11-3. 내부 친밀도
비주인공끼리는 플레이어의 선물 없이도 시간이 지나며 내부 친밀도가 오를 수 있다.  
다만 그 속도는 느려야 한다.

권장:
- 같은 종 장시간 인접 시 +1 / 20초
- 함께 탐험 완료 시 +3
- 같은 전투 생존 시 +5

## 12. 교배/임신/출산 시스템

## 12-1. 교배 해금 조건
플레이어 주도 교배:
- 양측 Adult
- 이성 조합
- 대상이 적색 아님
- 호감도 80 이상
- 근친 금지 규칙 위반 아님
- 현재 교배/임신/전투/탐험 상태 아님

## 12-2. 교배 상태
교배 시작 시:
- 두 카드가 하나의 결합 상태 스택으로 묶임
- 플레이어가 직접 집어 이동 불가
- 카드에 자물쇠/진행도 표시
- 상태명: `IntimacyLocked`

권장 시간:
- 기본 30초
- 희귀 종족 조합 45초
- 첫 교배 연출 60초

## 12-3. 결과 규칙
교배 종료 후:
- 성공/실패 판정
- 성공 시 여성 카드가 `Pregnant` 상태 진입
- 남성 카드는 `Recovery` 쿨다운
- 일부 종족은 다태 확률 또는 희귀 형질 확률 보유

## 12-4. 임신 규칙
권장 기본값:
- Human 계열: 2 Day
- Elf / Dwarf / Merfolk: 3 Day
- Orc / Ogre / Centaur / Lizardfolk: 2 Day

임신 중:
- 다시 교배 불가
- 전투 참여 제한 또는 패널티
- 상세 카드에 부모 예상 정보 표시

## 12-5. 출산 결과
출산 시 생성 카드:
- Child character card
- 이름 자동 생성
- 성별 결정
- 현재 종족 결정
- 부모 링크 저장
- Generation = Max(부모세대)+1

## 13. 혈통과 신종 규칙

## 13-1. 이번 단계의 보수적 방침
초기 버전은 시스템 난이도를 낮추기 위해 다음 순서로 간다.

### Phase A
- 자동 교배: 같은 종족만
- 주인공 교배: 인간 기원 + 해금 종족 조합 허용
- 출산 결과: 부모 중 하나 우세 종족 상속 + 희귀 혼혈 태그

### Phase B
- 특정 조합에서 완전 신종 탄생
- 예: Human-Origin + Elf -> Half-Elf lineage
- 예: Human-Origin + Centaur -> Ranger lineage
- 예: Human-Origin + Orc -> Brutal lineage

즉, **신종 폭발은 바로 다 열지 않고, 인간 기원 혈통을 중심으로 단계 해금**한다.

## 13-2. 권장 1차 자손 종족 판정
- 동일 종 교배: 동일 종 100%
- Human-Origin x Elf: 70% Elf형 / 30% Half-Elf 태그형
- Human-Origin x Dwarf: 70% Dwarf형 / 30% Half-Dwarf 태그형
- Human-Origin x Merfolk: 70% Merfolk형 / 30% Shoreborn 태그형
- Human-Origin x Orc: 60% Orc형 / 40% Half-Orc 태그형
- Human-Origin x Centaur: 80% Centaur형 / 20% Hybrid Rider 태그형
- Human-Origin x Ogre: 초반 비활성, 후반 해금 권장

이 방식은 종족 수를 폭증시키지 않으면서도  
"새 혈통이 나온다"는 감각을 확보한다.

## 20. 가장 중요한 제작 판단

이 게임의 성패는 카드 수가 아니라 **개체 서사 밀도**에 달려 있다.

좋은 방향:
- 카드 수는 적어도 한 장 한 장에 이름/상태/가계/취향이 있다
- 위치 선택이 곧 종족 선택이다
- 선물 선택이 곧 관계 설계다
- 전투 승리가 곧 새로운 교배 후보 확보다
- 출산이 곧 새로운 혈통 노드 생성이다

나쁜 방향:
- 카드 수만 많고 누가 누구인지 기억 안 남
- 변이는 랜덤만 강하고 의도 설계가 불가능
- 호감도는 숫자만 있고 취향이 체감되지 않음
- 가계도는 있는데 읽기 불편함
- 자동 생태가 너무 복잡하거나 너무 멍청함
