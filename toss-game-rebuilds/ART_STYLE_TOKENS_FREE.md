# ART STYLE TOKENS (FREE GAMES)

## 목표
- 전체이용가, 밝은 톤, UI 가독성 우선

## 컬러
- Primary: #5B7CFF
- Accent: #FF8F67
- Success: #9BE46F
- Background Dark: #0F0A21
- Text Main: #F6F4FF
- Text Muted: rgba(246,244,255,0.72)

## 화면 규칙
- 상단 15%, 하단 20%는 UI 안전영역 확보
- 복잡한 패턴 배경 금지, 캐릭터 대비 우선
- CTA 버튼은 1차/2차/3차 위계 유지

## 에셋 톤
- 둥근 실루엣, 과도한 디테일 금지
- 보상/성공 연출은 명확한 색 대비 사용
