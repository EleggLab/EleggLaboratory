# Research Hub

여기는 참고 문서, 외부 조사, PDF/텍스트 자료, 빠른 참조 묶음을 보관하는 허브다.

## Buckets

- `reference-library/`: 자주 열어보는 참고 묶음
- `openclaw/`: OpenClaw 관련 조사
- `nibel/`: Nibel 규칙과 메모
- `github-wide/`: 외부 레포지토리 조사 데이터

## Rule

- 실행 프로젝트에서 직접 빌드에 쓰지 않는 문서성 자료는 우선 여기 둔다.
- 날짜성 리포트는 가능하면 `topic-YYYY-MM-DD.md` 형식을 따른다.
