# Research Loop Ops Guide

## Daily Loop
1. `bash starter/scripts/refresh-research.sh`
2. `starter/backlog.md` 상위 5개 선택
3. prompts/scripts/checklists/docs에 1~2개씩 반영
4. `bash starter/scripts/verify.sh starter`
5. `bash starter/scripts/report.sh starter/starter-report.md`

## Weekly Loop
- top200 변화 확인 (`research/github-wide/reports/github-wide-top200.md`)
- low-value 카드 정리
- 반영 완료 항목 backlog에서 체크

## Metrics
- 이번 주 신규 카드 수
- starter 반영 커밋 수
- 체크리스트 추가/수정 건수
- verify 실패율
