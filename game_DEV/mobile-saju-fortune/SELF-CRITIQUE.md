# SELF-CRITIQUE

## 1. 계산 정확성(역법)
- 절기 경계 리스크: 현재 `ipchun` 판정은 `lunar-javascript` 절입 시각을 우선 사용하고, 계산 실패 시에만 2월 4일 근사값으로 폴백한다.
- 영향: 라이브러리 절기 데이터와 KASI 공식 API 간 불일치가 생기면 경계 시각대(입춘 전후)에서 년주 차이가 발생할 수 있다.
- 자시 처리 리스크: 기본값 `23-01_nextDay`는 23시 보정 중심이다. 00:xx 경계나 학파 변형은 옵션 확장이 필요하다.
- 음력 윤달 리스크: `manseryeok` 입력 검증에 의존하므로, 드문 윤달 경계 케이스는 교차검증 벡터를 더 늘려야 한다.
- 태양시 보정 리스크: 경도 기반 태양시 보정은 구현했지만, 방정시(EoT)까지 반영한 정밀 보정은 아직 미구현이다.
- 월운(월별 보기) 리스크: 현재 월운은 "양력 해당 월 15일 12:00"을 기준으로 월주를 산정한다. 절기 절입 시각에 따른 정확한 월 경계가 아니므로 월 초 경계(절입 전후) 사용자에겐 결과가 다르게 느껴질 수 있다.
- 수정 계획:
  1) KASI 24절기 API(절입 시각) 조회/캐시를 추가하고, 입춘/월주 경계를 시각 단위로 검증
  2) 자시 옵션을 `sameDay`, `nextDay`, `midnightSplit` 3종으로 확장
  3) 윤달/경계 벡터를 API 교차검증 기반으로 30개 이상 추가
  4) 태양시 보정에 방정시(EoT) 요소를 추가해 분 단위 정확도 개선
  5) 월운은 `절기월`/`양력월(근사)` 모드로 분리하고 UI에 기준을 명시

## 2. 명리 규칙(피처)
- 십성 매핑 리스크: v1 규칙을 고정했지만, 학파별 정/편 배정 차이를 완전 해소하지 못했다.
- 지장간 가중치 리스크: `all_weighted(0.5/0.3/0.2)` 모델은 실무적 기본값이며, 문헌별 가중 분포 차이가 존재한다.
- 강약 모델 리스크: `advanced_v1`는 설명 가능한 점수화를 우선했지만 아직 경험적 캘리브레이션이 부족하다.
- Q&A 도메인 매핑 리스크: 재성/관성/인성 등을 금전/연애/부모 등으로 연결하는 방식은 문화/학파 차이가 크다. 현재는 "가능성/경향" 표현으로 단정을 줄였으나, 더 많은 근거와 예외 처리(조건부 문장)가 필요하다.
- 수정 계획:
  1) `docs/DECISIONS.md`에 십성/지장간 대안 규칙표(v2 후보) 추가
  2) 강약 모델 검증용 리그레션 샘플 100건 확장
  3) Q&A 템플릿에 근거 문장/출처를 더 보강하고 버전(`qna_snippets.v2`)로 변경 이력을 관리

## 3. Q&A/서사(해석)
- AI 제거로 "환각" 리스크는 없지만, 템플릿이 과도하게 일반적이거나 사용자 상황을 충분히 반영하지 못할 수 있다.
- 연/월 운을 반영할 때, 현재는 연운(년간)과 월운(월간) 십성 포인트를 중심으로만 덧붙인다. 실제 해석에서 쓰는 합/충/형/파/해의 맥락은 더 확장 여지가 있다.
- 고위험 도메인: 건강 항목은 의료 조언이 되지 않도록 일반 루틴 중심으로 제한했지만, 사용자 입력이 구체적 질병/치료로 흐를 수 있어 안내 문구 강화가 필요하다.
- 수정 계획:
  1) 도메인별 추가 입력(직업군/결혼 여부/자녀 유무 등)을 "선택"으로 받아 Q&A를 더 정확히 개인화
  2) 운(연/월) 선택 시 "근거 값" 섹션을 더 강조하고, 사용자가 스스로 비교 가능하게 개선
  3) 합/충/형/파/해를 도메인 문장에 조건부로 삽입하는 규칙 레이어 추가

## 4. UX
- 장점: 요약/상세/Q&A/설정 탭으로 정보 밀도를 분리했고, 입력은 계산 후 자동으로 접혀 결과에 집중하게 했다.
- 장점: 모델명/코드값을 직접 노출하기보다 사용자 친화 라벨(오행 집계 방식)을 사용했다.
- 리스크: 모바일에서 상세 테이블(십성/대운)이 길어질 때 스크롤 피로가 높다.
- 리스크: 설정 옵션이 많아 초심자에게 진입장벽이 생길 수 있다(다만 고급 사용자는 옵션을 원한다).
- 수정 계획:
  1) 모바일 전용 축약 카드 + "핵심만 보기" 토글 추가
  2) "기본 추천 옵션" 프리셋 버튼 + 설명 툴팁 추가
  3) 설정 변경 시 결과 차이 비교(전/후 하이라이트) 기능 추가
