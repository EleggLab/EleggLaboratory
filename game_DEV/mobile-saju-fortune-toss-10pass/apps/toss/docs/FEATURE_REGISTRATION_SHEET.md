# 기능 등록 시트

토스 콘솔 기능 소개는 너무 넓게 펼치기보다 핵심 사용자 흐름 3개 안쪽으로 정리하는 쪽이 안전합니다. 현재 앱 기능은 많지만, 콘솔 소개용 대표 기능은 아래처럼 묶는 것을 기준으로 둡니다.

## 대표 기능 1
- 이름: 오늘 운세
- 진입 경로: `/today`
- 설명: 가볍게 하루의 분위기와 해석을 빠르게 확인하는 진입 기능

## 대표 기능 2
- 이름: 사주 풀이
- 진입 경로: `/saju`
- 설명: 생년월일과 시간 입력 후 핵심 해석과 세부 운세를 확인하는 메인 기능

## 대표 기능 3
- 이름: 타로 · 주역
- 진입 경로: `/tarot`
- 설명: 직관형 카드 풀이와 질문형 주역 흐름을 함께 제공하는 확장 기능

## 비고
- 홈 `/` 은 대표 기능 허브로 설명하고, 별도 기능 항목으로 세지 않는 편이 깔끔합니다.
- `/tarot/result`, `/tarot/reading` 은 세부 흐름 화면이므로 콘솔 소개에서는 `/tarot` 아래 하위 단계로 묶습니다.
- 실제 앱에는 `/iching` 탭이 분리되어 있지만, 콘솔 소개 문구는 `타로 · 주역` 한 항목으로 합쳐도 무방합니다.
