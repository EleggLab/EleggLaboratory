# UGC Runtime Data

`story_tree.json` is the runtime story payload loaded by `script.rpy`.

Do not edit this file directly in normal workflow.

Edit source:
- `../../content/story_tree.json`

Then run:
- `python ../../tools/validate_tree.py ../../content/story_tree.json`
- `python ../../tools/build_renpy_story.py --source ../../content/story_tree.json --target story_tree.json`
