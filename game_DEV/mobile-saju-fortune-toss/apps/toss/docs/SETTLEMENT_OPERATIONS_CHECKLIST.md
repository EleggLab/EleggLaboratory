# 정산 운영 체크리스트

현재 배포 방향은 광고 없는 무료 앱이라 즉시 필수는 아닙니다. 다만 이후 토스 광고를 다시 켤 수 있도록 운영 체크리스트를 같이 보관합니다.

## 워크스페이스 준비
- [ ] 필요 약관 동의 완료
- [ ] 대표 관리자 권한 확인
- [ ] 정산 정보 심사 승인 완료

## 정산 입력물
- [ ] 예금주와 일치하는 통장 사본 준비
- [ ] 광고 운영 담당자 지정
- [ ] 팝빌 역발행 승인 담당자 지정

## 운영 점검
- [ ] 광고를 켠 다음날 대시보드 수치 확인
- [ ] 익월 정산 반영 내역 확인
- [ ] 월말 지급 전 역발행 승인 완료

## 메모
- 광고를 켜지 않는 동안에는 이 문서를 참고용으로만 유지합니다.
- 광고를 다시 켜는 시점에는 `docs/AD_SLOT_SHEET.md` 와 함께 재검토합니다.
