# StackCraft Style Lock Stage 2

## 목표
- Stage 1 결과에서 `A`와 `F`만 남겨 2차 정제
- 실루엣/검은 덩어리/유아틱함 감소
- 같은 스타일 안에서 종족이 달라도 한 세트처럼 보이는지 검증

## 선택된 가족
### A2. Refined Pink Gothic
- 핑크/블랙 고딕 라인 유지
- 눈, 손, 입, 옷 디테일 가독성 강화
- 실루엣처럼 뭉개지는 검은 면적 축소

### F2. Refined Adventurer
- 카드게임용 직업/종족 가독성 강화
- 모험가 실루엣 유지
- 성인 캐릭터성 유지

## 검증 포인트
- human / elf / succubus / wolfkin / tiefling / dragonkin / goblin까지 읽히는가
- 여성/남성 모두 같은 화풍으로 유지되는가
- 흰 배경 전신 스탠딩 조건이 지켜지는가
