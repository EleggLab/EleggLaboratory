# Development Roadmap

## Phase 1: Pre-production
- Define genre, controls, and target platform
- Create wireframe and UX flow
- Pick engine and project stack

## Phase 2: Prototype
- Build one playable stage
- Validate control feel and pacing
- Add temporary art and audio

## Phase 3: MVP
- Add progression and augment system
- Add stage variety
- Add basic balancing and polish

## Phase 4: Launch Prep
- QA pass
- Performance optimization
- Store assets and release plan
