# 앱 등록 시트

## 기본 식별자
- 한글 앱명: 종합 운세
- 콘솔 앱명 `appName`: `__SET_CONSOLE_APP_NAME__`
- 부제: 사주, 타로, 주역, 오늘 운세를 한곳에서
- 카테고리 제안: 라이프스타일
- 검색 키워드 제안: 운세, 사주, 타로, 주역, 오늘운세, 점

## 브랜드
- 표시 이름: 종합 운세
- 대표 색상: `#F7C948`
- 아이콘 URL: `__SET_TOSS_BRAND_ICON_URL__`

## 고객 지원
- 고객센터 이메일: `__SET_CUSTOMER_SERVICE_EMAIL__`
- 고객센터 전화번호: `__SET_CUSTOMER_SERVICE_PHONE__`
- 고객센터 채팅 URL: `__SET_CUSTOMER_SERVICE_CHAT_URL__`

## 콘솔 자산
- 앱 로고: `assets/console/app-logo.png`
- 정사각 썸네일: `assets/console/thumbnail-square.png`
- 가로형 썸네일: `assets/console/thumbnail-landscape.png`
- 세로 검색 스크린샷 3장:
  - `assets/console/screenshot-portrait-1.png`
  - `assets/console/screenshot-portrait-2.png`
  - `assets/console/screenshot-portrait-3.png`

## 메모
- `TOSS_APP_NAME` 와 실제 콘솔 `appName` 은 완전히 같아야 합니다.
- 콘솔 자산은 현재 앱 리소스를 바탕으로 만든 준비용 초안입니다. 출시 전 최종 디자인 교체를 권장합니다.
- 이 문서, `.env`, `assets/console/asset-manifest.json` 은 항상 같이 맞춰야 합니다.
