# StackCraft Style Lock Stage 2 Curation

## 결과
- 우승 가족: `A2 Refined Pink Gothic`
- 차선 참고 가족: `F2 Refined Adventurer`

## A2 평가
- 장점: 한 스타일 가족으로 보일 정도의 통일감이 생김
- 장점: 인간/엘프/티플링/울프킨까지 같은 세계관 아트처럼 읽힘
- 장점: 핑크/블랙/굵은 선/흰 배경 조건이 안정적
- 단점: 일부 종족은 검은 면적이 여전히 커서 디테일이 죽음
- 단점: 종족별 의상 변화폭이 아직 작음

## F2 평가
- 장점: 직업/판타지 장비 가독성은 좋음
- 장점: 카드게임용 직업 로스터에는 활용 가치가 있음
- 단점: 화풍 편차가 큼
- 단점: 남성/비인간 종족에서 실루엣 장난감처럼 보이는 컷이 남아 있음

## 유지할 컷
- `a2_human_female`
- `a2_elf_female`
- `a2_tiefling_female`
- `a2_wolfkin_female`
- `f2_human_female`
- `f2_elf_female`
