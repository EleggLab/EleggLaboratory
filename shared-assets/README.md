# Shared Assets

여기는 여러 프로젝트에서 재사용하거나, 프로젝트 경계를 넘어서 보관해야 하는 자산 허브다.

## Buckets

- `art/`: 공용 아트 팩, 임시 UI 시안, 런타임 아트 팩
- `characters/`: 캐릭터 원본 자산
- `project-docs/`: 특정 프로젝트의 원본 문서이지만 코드 프로젝트 밖에서 보존해야 하는 문서
- `nibel/`: Nibel 관련 공용 자산
- `risu/`: Risu 공용 자산과 가공 결과

## Rule

- 프로젝트 하나만 쓰는 실행 자산은 프로젝트 내부에 둔다.
- 여러 프로젝트가 공유하거나 원본 보존 목적이면 여기 둔다.
- 새 디렉터리는 영어 `kebab-case`를 기본으로 한다.
