플레이테스트

단순화 기준

이번 툴은 기존 레거시 프로젝트보다 훨씬 가볍게 유지합니다.

  • 장면 하나에는 사건 하나만 둡니다.
  • 선택지는 보통 2~3개만 둡니다.
  • 효과는 능력치 변화 1개, 플래그 변경 1개 정도로 제한합니다.
  • 전투, 장비, 초상화, 자동 생성 서사는 기본 기능에서 제외합니다.
