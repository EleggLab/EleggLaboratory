The issue is structural, not a missing file.

- The user-provided tiger image is already inside the project and synced correctly.
- The list tile path is fine.
- The wrong image appears after entering detail because the detail screen still resolves its main hero from the `detail`-side asset flow instead of strictly forcing the tiger reference source for the hero.

- `tileIcon` behavior is mostly correct.
- `detailHero` behavior for tiger is not fully locked yet.
