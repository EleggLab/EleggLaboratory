## Image Analysis

### 1. 홈
- 아스트라 원화는 정상 노출된다.
- 문제는 이미지 자체보다 상단/하단 스크림이 `띠처럼 겹쳐 보이는 것`이었다.
- 이번 라운드에서는 스크림 레이어를 더 촘촘하게 늘리고 전체 오버레이 강도를 낮췄다.

### 2. 데일리 목록
- 목록은 기능상 동작하지만 카드 내부 여백이 커서 이미지가 작아 보였다.
- 특히 `호랑이띠`는 실제 아이콘 파일이 상세형 일러스트와 같은 자산이라, 아이콘처럼 보이지 않았다.
- 이번 라운드에서는 `호랑이띠`만 별도 crop 메타를 두어 얼굴/상단부가 보이도록 조정했다.

### 3. 별자리 상세
- 상세 페이지는 경로가 없는 게 아니라, 실제 CDN 이미지가 있는데 화면에서는 blank처럼 보였다.
- 이번 라운드에서는 상세 이미지 프레임 안에 `아이콘 underlay`를 같이 깔아, 상세 로딩이 불안정해도 시각적으로 빈 화면이 되지 않게 했다.

### 4. 타로 허브
- 허브 카드가 너무 커서 화면 밀도가 약했다.
- 특히 상단 `오늘의 운세` 카드와 4개 모드 카드가 “내용보다 빈 영역이 더 커 보이는 상태”였다.
- 이번 라운드에서는 카드 높이, 패딩, 타이포, 액센트 길이를 줄여 밀도를 높였다.

### 5. 하단바
- 초기에는 텍스트 글리프처럼 보여 임시 UI 느낌이 강했다.
- 현재는 코드 기반 도형 아이콘으로 교체된 상태다.
- 아직 최종 시안 고정 전이므로, 선택 대비와 선 굵기만 추후 한 번 더 다듬으면 된다.
